# CONTROL V44 — الرسائل التلقائية حسب الكاتقوري

نسخة مخصصة للرسائل فقط. حُذفت أدوات البث والكام والمايك وYouTube وTwitch والتحكم بدخول الرومات وإعادة الدخول، مع ملفاتها واعتمادياتها وأدوات FFmpeg وChromium وXvfb. الاتصال بحسابك يراقب وجودك في الفويس فقط، ولا يدخل أي روم نيابة عنك.

## طريقة الاستخدام

1. ارفع ملفات هذه النسخة بدل ملفات المشروع القديم وأعد النشر.
2. افتح `/لوحتي`. الحسابات الموجودة في MongoDB تبقى مرتبطة. للمستخدم الجديد اضغط «دخول» وأدخل توكن حسابه في نافذة Discord الخاصة.
3. اضغط «إعدادات الرسائل» وأدخل أيدي السيرفر، وأيدي الكاتقوري الذي يحتوي رومات الفويس، وأيدي روم إرسال الرسالة، والمدة بالدقائق، ونص الرسالة.
4. مثال: اكتب `40` لإرسال الرسالة بعد 40 دقيقة. المدة من 1 إلى 1440 دقيقة، وتُقبل الأرقام العربية مثل `٤٠`. اكتب النص فقط؛ يُضاف بعده مسافة واسم رومك الصوتي الحالي تلقائيًا، بدون منشن. مثال: النص `Room` وأنت داخل روم اسمه `الرس` ينتج `Room الرس`. الحد النهائي للنص والمسافة واسم الروم معًا 2000 حرف، ويدعم النص الأسطر المتعددة.
5. اضغط «تفعيل تلقائي». يتغير نفس الزر إلى «إيقاف تلقائي»؛ الضغط عليه يلغي العدّ والإرسال التالي فورًا.
6. استخدم `/setup` لإرسال لوحة دخول عامة جديدة مكان القديمة. الأمر يحتاج صلاحية إدارة السيرفر. كل عضو يتحكم بحسابه من الخاص.

## سلوك الوقت

- يبدأ العد عند وجود حساب التوكن نفسه داخل أي روم صوتي أو Stage تحت الكاتقوري المحدد.
- الإرسال يكون من الحساب المرتبط إلى الروم الذي حددته، ويدعم الشات النصي وشات الروم الصوتي والثريد المفتوح. يجب أن يكون الروم داخل السيرفر نفسه؛ لا يشترط أن يكون تحت الكاتقوري المراقب.
- بعد انتهاء المدة يُرسل النص المحفوظ ثم مسافة واحدة واسم الروم الصوتي الذي أنت داخله وقت الإرسال، ثم يبدأ عدّ جديد بالمدة نفسها ما دمت داخل الكاتقوري. يُقرأ الاسم مجددًا في كل إرسال، بما يشمل التنقل بين الرومات أو تغيير اسم الروم. لا يُضاف أيدي الروم أو منشن له، ولا يُحفظ اسم الروم ضمن نصك.
- مغادرة الفويس أو الانتقال خارج الكاتقوري تلغي العدّ. عند العودة تبدأ المدة كاملة من جديد.
- الانتقال المباشر بين رومات نفس الكاتقوري وتغيير الميوت أو الدفن لا يصفّران الوقت. إذا وصل حدث خروج حقيقي ثم دخول، تُعد جلسة جديدة.
- تفعيل التلقائي وأنت داخل الكاتقوري يبدأ مدة كاملة من لحظة التفعيل.
- تعديل الإعدادات أثناء التشغيل يعيد العدّ من البداية بعد الحفظ، إذا كنت داخل الكاتقوري الجديد.
- إعادة تشغيل الخدمة أو فقد اتصال المراقبة تلغي العدّ الجاري. يبدأ عدّ كامل بعد تأكيد وجودك مجددًا؛ لا تحسب الخدمة وقتًا لم تتمكن من مراقبته، ولا ترسل رسائل لتعويض وقت التوقف.
- تظهر الحالة والموعد القادم في اللوحة. استخدم «تحديث» عند الحاجة؛ التوقيت النسبي يظهر من Discord نفسه.
- لا تُرسل رسالة فورية بمجرد التفعيل أو الدخول. تمنع الخدمة الإرسال عند غموض الحالة الصوتية.
- تحترم Slowmode وحدود Discord. أخطاء الاتصال تؤجل المحاولة، وأخطاء التوكن والصلاحيات توقف التلقائي وتظهر في اللوحة. تعذر الحفظ يوقف الإرسال حتى إصلاح الاتصال وإعادة التفعيل.
- المنشنات في نص الرسالة لا تولد تنبيهًا جماعيًا؛ هذا هو سلوك النسخة السابقة أيضًا.

## الترقية من V43

أبقِ نفس `MONGODB_URI` و`MONGODB_DB_NAME` وخصوصًا **نفس `TOKEN_ENCRYPTION_KEY`** حتى تُقرأ الحسابات المشفرة القديمة. لا تنشئ مفتاحًا جديدًا لحسابات موجودة.

تُحفظ الحسابات وأيديات لوحات الخاص الموجودة. تُزال إعدادات الرومات والبث القديمة من سجل كل حساب عند التشغيل. إعدادات الإرسال العشوائي القديمة تُعاد إلى وضع متوقف لأن النظام الجديد يحتاج كاتقوريًا ورسالة ورومًا محددين. اضبطها مرة واحدة ثم فعّل التلقائي.

كل الحفظ في MongoDB، ولا حاجة إلى `DATA_DIR` أو قرص محلي أو `MONGODB_MIGRATE_LEGACY`. ارفع هذه النسخة كاملة مع `package-lock.json` و`Dockerfile`، واحذف ملفات النسخة القديمة المستبدلة. شغّل **نسخة خدمة واحدة فقط** على قاعدة البيانات نفسها حتى لا تُكرر الرسائل من عمليتين متزامنتين. أوقف نشر V43 القديم عند تشغيل V44.

## Environment Variables

| المتغير | المطلوب |
| --- | --- |
| `DISCORD_BOT_TOKEN` | توكن بوت لوحة التحكم |
| `DISCORD_APPLICATION_ID` | أيدي تطبيق البوت |
| `DISCORD_PUBLIC_KEY` | المفتاح العام من صفحة General Information |
| `TOKEN_ENCRYPTION_KEY` | مفتاح التشفير السابق؛ 32 بايت بصيغة hex أو Base64 |
| `MONGODB_URI` | رابط MongoDB في متغير البيئة فقط |
| `MONGODB_DB_NAME` | اسم قاعدة البيانات السابقة؛ الافتراضي `control` |
| `PORT` | تضبطه الاستضافة، والافتراضي محليًا `3000` |
| `MAX_ACCOUNTS` | اختياري؛ `0` يعني بدون حد محلي للحسابات |

لا يحتوي المشروع أي توكن أو رابط قاعدة بيانات حقيقي. لإنشاء مفتاح جديد **لتثبيت جديد فقط**: `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`.

## Discord والاستضافة

في Discord Developer Portal أبقِ `Interactions Endpoint URL` على `https://YOUR-SERVICE.onrender.com/discord/interactions`. يحتاج بوت التحكم صلاحية مشاهدة الروم وإرسال الرسائل وEmbed Links، ويجب تفعيل الخاص لاستقبال اللوحة. لا يحتاج بوت التحكم الدخول إلى سيرفر الكاتقوري المراقب إذا كان الحساب المرتبط يستطيع الوصول إليه. حساب التوكن يجب أن يملك مشاهدة الكاتقوري وروم الإرسال وصلاحية الكتابة فيه.

اللوحة تعمل عبر استقبال التفاعلات الموقعة عبر HTTPS؛ لا يعتمد عمل الأزرار على ظهور بوت التحكم بحالة Online. يتصل حساب المراقبة بـGateway لقراءة تغيرات الفويس فقط.

التشغيل على Node.js 22.4 أو أحدث، وDocker المرفق يستخدم Node.js 24:

```bash
npm ci --omit=dev --ignore-scripts
npm start
```

التشغيل محليًا مع ملف `.env` تنسخه من `.env.example`: `node --env-file=.env index.js`.

الفحص: `npm test`. فحص قراءة MongoDB دون تعديل: `npm run check:mongodb` بعد ضبط البيئة. مسار الصحة `/health`.

## التحقق

تشمل الاختبارات المؤقتات، الدخول والخروج والتنقل والميوت، إعادة الاتصال وإعادة التشغيل، تغيير الإعدادات والتوكن، منع تداخل الحسابات، إلغاء إرسال معلّق، إعادة المحاولة وSlowmode، تشفير MongoDB، وملكية الأزرار وتوقيع تفاعلات Discord. الاختبارات تستخدم بيانات ومحاكاة محلية؛ لا تسجل دخولًا إلى حساب حقيقي ولا ترسل رسائل فعلية.

## تحديث مؤقت الروم والحد اليومي
- تظهر مدة الدخول كتوقيت نسبي في اللوحة، مع موعد الإرسال القادم.
- يُحذف الرمز `・` من اسم الروم قبل الإرسال.
- لكل اسم روم رسالتان يوميًا: الأولى دون رقم، والثانية ينتهي نصها بـ `2`.
- العدّاد محفوظ في MongoDB ولا يتصفّر بالخروج أو إعادة التشغيل أو تعديل الإعدادات.
- يتصفّر عند 00:00 بتوقيت السعودية، ويبدأ انتظار المدة المحددة مجددًا إذا بقي الحساب داخل الكاتقوري.

### عدّاد مستقل لكل اسم روم
تغيير الروم يبدأ المدة من جديد حتى داخل نفس الكاتقوري. يُحفظ عدد الرسائل لكل اسم روم بعد إزالة `・`؛ الرجوع لروم أُرسلت فيه الأولى يجعل الإرسال التالي برقم 2، والروم الذي أُرسلت فيه رسالتان ينتظر اليوم التالي. رومان لهما الاسم المنظّف نفسه يشتركان في الحد اليومي. لا يوجد حد إجمالي للرسائل في جميع الرومات.
